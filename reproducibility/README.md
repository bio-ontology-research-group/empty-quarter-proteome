# Reproducibility

Every tracked number and figure in the public manuscript snapshot (`../manuscript/main.tex`) is regenerated and
checked from this folder against curated result tables in `../results/` and compact checksum-frozen inputs here.
The private `../paper/` submodule is optional and, when present, can be synchronized into the public snapshot with
`sync_manuscript_snapshot.sh`. Historical cluster-scale claims are closed through checksum-pinned
claim/value/source ledgers; no workstation workbench symlink is needed. The verifier also rejects a curated list
of superseded or unbounded exact phrases and bounded-pattern violations throughout active manuscript, RQ, result
and scope documents. This is a regression guard, not a semantic checker.

## Run it

```bash
bash reproducibility/run_all.sh          # figures + numbers + manifest + manuscript -> REPORT.md
```

or the pieces:

```bash
python3 reproducibility/verify.py            # recompute & check every paper number (PASS/FAIL table)
python3 reproducibility/verify.py --manifest # dump the claims manifest as TSV
bash    reproducibility/regenerate_figures.sh # rebuild all 11 figure PDFs into ../figures/
python3 RQ/E2/run.py                          # rebuild the bounded historical B4 screen products
bash    reproducibility/build_manuscript.sh   # Latexmk/BibTeX build; reject unresolved citations/references
```

`verify.py` exits non-zero if any **COMPUTE** or **FROZEN** extraction disagrees with the registered manuscript
value, a TABLE source is absent, any frozen artifact changes, or a claim-boundary guard fails. It therefore works
as a fail-closed local CI gate without pretending to rerun cluster-scale analyses.

| `historical_provenance_ledger.tsv` | exact value/source registry for cluster-scale historical claims (no local heavy recomputation) |

## The four tiers

Each claim in `verify.py` is one of:

- **COMPUTE** — recomputed from a local analysis table and checked numerically against the registered manuscript
  value (for example A1/A2/A4/A5, B2 medians, B3 abundance, the retained historical C1 snapshot, the
  cross-catalogue specificity intersection and the bounded B4 products).
- **FROZEN** — extracted or derived from a compact SHA-256-pinned result artifact and checked numerically. This
  verifies artifact integrity and manuscript extraction for the canonical catalogue, R232 taxonomy, historical
  tier closure and current structure calibration; it does **not** rerun the upstream IBEX/Orix computation.
- **TABLE** — the value is the recorded statistic of a curated source-of-truth computation that is not cheap
  to re-run locally (for example a 16-sample GEM/SMETANA p-value or archived PERMANOVA/MWU outputs). The
  generating script lives in `../code/` (e.g. `phase_d_endemism.py`, `smetana_analysis.py`)
  and the value is stored in the cited result. `verify.py` checks source presence only; it does not parse or
  independently validate the value.
- **PROVENANCE** — produced by heavy IBEX/ORIX pipelines (51.9 M-protein clustering, UniRef50/AFDB search and
  ESMFold). `historical_provenance_ledger.tsv` is SHA-256-pinned and must close exactly against every registered
  value and upstream source. This checks deposition/transcription, while deliberately not claiming that the remote
  path or heavy computation was rerun locally. To regenerate, see `../workbench/scripts/` and the job ledger.

## Data dependencies (all present locally)

The repository can build and run its compact verifier in a clean clone without the private `paper/` submodule.
To execute the full harness, restore the seven checksum-listed large inputs and verify their hashes first:

```bash
IBEX_USER=<kaust-id> bash reproducibility/fetch_large_files.sh
bash reproducibility/run_all.sh
```

- `../results/` — curated tables promoted from the workbench (committed with the paper), plus the checksum-listed
  large matrices restored by `fetch_large_files.sh`.
- `./canonical_catalogue_summary.json` and `./r232_*` — compact current catalogue/taxonomy closure. Their
  byte-identical workbench sources and hashes are in `current_manuscript_artifacts.tsv`.
- `./historical_mag_novelty_class.tsv` — committed, checksum-pinned GTDB novelty classes for the historical
  functional snapshot; regenerate it from the two GTDB-Tk summary tables with
  `python3 code/freeze_historical_mag_novelty.py`.
- `./dnds_legacy_provenance.tsv` and `legacy/83_extract_isdark_faa.sh` — exact provenance for the historical
  sequence-dark/NG86 arm. The harness checks both the ledger hash and each listed source; it does not promote the
  archived unclustered p-values to selection inference.

## Corrections this harness has already caught

- The old R226/single-sample census (15,469 MAGs, 44 named phyla and 17 domain-unplaced bins) was replaced for
  taxonomy by the canonical R232 ANI95 census: 14,426 refined bins, 5,438 HQ/MQ representatives, 51 named phyla,
  and no first gap at domain, phylum or class. The historical 15,469-MAG functional snapshot remains explicitly
  labelled and is never treated as the current taxonomy catalogue.
- The historical tier1 and tier2 assembly-protein inputs exceed the recorded UniRef50-dark total by 151,400.
  They are now disclosed as non-closing workflow snapshots rather than presented as a partition.
- The current full-coordinate structure refresh replaces the old RQ/A3 threshold table as the headline and
  reports both score normalisations. Query-normalised TM gives 608/1,875 candidate dual no-hits and 101/3,013
  false no-hits in known-fold controls; alignment-normalised TM gives 97/1,875 and 68/3,013. Candidate/control
  cohorts are not covariate matched, and neither definition is a new-fold call. Candidate and control no-hits
  are each decomposed into no-row retrieval failures versus retrieved rows below the named threshold, before
  and after the gate.
- The R232 order-gap disposition now closes all 11 representatives: ten entered de novo trees and none advanced
  as an order proposal; one MQ candidate failed the marker-alignment coverage gate and is explicitly tracked in
  the 48_S recovery rather than silently disappearing from the denominator.
- The historical PICRUSt2 sensitivity columns are now labelled by their actual denominator rules. The published
  2.40/1.11 ratios threshold PICRUSt2 while retaining fixed MAG any-presence; applying the same relative-abundance
  threshold to both sides yields 31.41/14.63. Neither is presented as a biological enrichment.
- The B2 dN/dS comparator was withdrawn. Its deterministic selection reduced
  the control support to 28 source samples versus 430 for the dark arm, and
  UniRef detectability is itself related to evolutionary rate. The harness now
  verifies only the bounded dark-family result and its family-size sensitivity;
  exact historical sources and hashes are in `dnds_legacy_provenance.tsv`.
