1. **Never fall back to Stage 1 provisional promotion Booleans**: Stage 3 MUST consume the Stage 1b verified outputs (`final_candidate_promotion_eligible == True` and `verified_complete_interior_member == True`).
2. **All supporting member loci verified against `genome_manifest.tsv` refined FASTAs**:
   - Every one of the 237 authoritative refined Thermoplasmatota MAG FASTAs (`inputs/thermo237_refined_mags.tar.gz`) is verified against `inputs/genome_manifest.tsv` for exact SHA-256, contig count, base count, and zero duplicate contig IDs (`provenance_status == 'verified_exact_match_genome_manifest'`).

   - Family recurrence counts (`n_verified_complete_interior_member_loci`, `n_verified_complete_interior_genomes`, `n_verified_independent_genus_blocks`) are computed **exclusively** from member loci with `verified_complete_interior_member == True`.
3. **Representative-own (`rep_own_*`) vs Family-member (`family_*`) evidence strictly separated**:
   - `rep_own_*` columns report raw structural/profile/domain evidence joined strictly by exact protein ID to `actual_representative_gene` (`actual_representative_cat_id`).
   - Explicit per-source pLDDT scale (`rep_own_plddt_source_scale == '0_to_1'`) is enforced with bounded range checks.
   - `rep_has_qualified_pdb_structural_support` requires a qualified model on `actual_representative_gene` (`rep_coord_aa_length >= 100`, `plddt_0to1 >= 0.70`, `rep_own_model_length_matches_cds == True`) AND a Foldseek PDB hit with `rep_own_pdb_qtmscore >= 0.50` and `rep_own_pdb_qcov >= 0.50`.
   - AFDB E-value alone does NOT count as whole-fold structural support (`rep_own_afdb_qtmscore_status == 'unavailable_in_c9_afdb_table'`).
   - Family-aggregate / other-member evidence (`family_struct_model_member_id`, `family_pdb_match_member_id`, `family_hhsearch_member_id`, `family_interpro_rep_member_id`, `family_interpro_anymember_bits`, `family_c6_contributing_genes`) is stored in separate `family_*` columns with explicit contributing member IDs and is never relabelled `rep_own_*`.
