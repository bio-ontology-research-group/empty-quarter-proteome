# SUPERSEDED: V2 Cropped Region Pilot (2026-10-13)

This V2 pilot (Slurm Job 53700779, N=300 models, 413 regions, `--max-seqs 50`) is preserved intact and superseded by the V3 full-cohort census (`scripts/v3_crop_and_search_regions.py`, `scripts/v3_full.sbatch`, N=5,851 models) per `reviews/darkmatter-2026-10-13/round6/h4_review1/`.

### Reasons for Supersedure by V3:
1. **C1 (`--max-seqs 50` Hit-List Saturation in Controls)**: V2 filtered a `--max-seqs 50` output list post hoc for sequence identity Tiers 2–4 (`fident < 0.30, 0.25, 0.20`), conflating hit-list exhaustion by close PDB homologs (17/17 at Tier 2 and 21/22 at Tier 3 with `total_hits_raw == 50`) with low-scoring alignments. V3 searches with `--max-seqs 1000` and explicitly separates `POST_EXCLUSION_EMPTY` from `PERSISTENT_LOW_SCORE` and `RAW_ZERO_RETRIEVAL`, reporting both unconditional and remaining-hit conditional match rates alongside saturation flags.
2. **C2 (`NO_CONFIDENT_REGION` vs `ZERO_RETRIEVAL`)**: V2 classified 11 pilot models having `n_confident_regions == 0` (`cropped_pdb == "NONE"`) as `ZERO_RETRIEVAL`. V3 separates `NO_CONFIDENT_REGION` from `RAW_ZERO_RETRIEVAL` and reports both unconditional and region-eligible conditional recovery rates.
3. **C3 (Whole-Chain vs Cropped Exclusion-Tier and Reference Asymmetry)**: V2 read whole-chain baseline `wc_qtm` from Tier 0 unfiltered tables while evaluating crops at Tiers 1–4, defined strata on `PDB + AFDB` while searching crops against `PDB` only, and masked baseline-matched models that lost their match upon cropping. V3 executes same-run whole-chain and cropped PDB searches (`--max-seqs 1000`, identical 21-column format with `fident` and `cigar`), applies Tiers 0–4 symmetrically to both whole-chain and cropped hits, separates `K_local_pdb` ($n=849$) from `K_local_afdb_only` ($n=87$) and `Q_not_K_pdb` ($n=1,107$) from `Q_not_K_afdb_only` ($n=700$), and tracks both match recovery and match retention/loss.
4. **C4 (Length-Stratified Pilot Weighting vs Full Census)**: V2 reported unweighted pilot averages across equal-allocation length bins in `K_local`. V3 executes the complete finite cohort census ($N = 5,851$ models) and also archives the Horvitz–Thompson design-weighted pilot audit (`68.15%` vs `70.00%` unweighted).
5. **C5 (Exact Aligned Residue Pairs via `cigar` & Statistical Reporting)**: V3 parses exact aligned residue pairs (`M` operations from Foldseek `cigar`, verified equal to `qspan + tspan - alnlen`) distinct from query coordinate span (`qend - qstart + 1`), aggregates all tiers to the parent model unit, reports retrieved-only mean sequence identity, and corrects the paired self-hit exclusion audit.
